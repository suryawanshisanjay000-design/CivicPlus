IMPORTANT:
The original CivicPulse specification was intentionally simplified here.
The objective is a reliable end-to-end MVP, not a full government production
platform.

Primary success criterion:
Anonymous report -> database -> triage -> SLA -> officer -> resolution proof
-> public tracking.

Do not add complexity until this path is working.
